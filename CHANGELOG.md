# Changelog

## 1.0

- Initial public source version of the Android static recompilation port.
- ARM64 and ARM32 native builds with an OpenGL ES 3.0 renderer.
- Touch controls, layout editing, touch menus and character selection.
- Widescreen gameplay and optional panorama archive.
- LAN room discovery and two-/three-player co-op lobby.
- External game-data installation, Japanese/Russian data selection and persistent saves.
- Native stage3 TV update path and resource-lifetime fixes.
- External pinned source dependencies, separate port patches and shared launcher lookup.

Original game files, compiled APKs, signing material and private development
history are excluded from the public source branch.
